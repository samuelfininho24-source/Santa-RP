# Santa Bot

Bot Discord de IDs de 00 até 1000.

## Comandos
- `/id` — recebe o próximo ID ou retorna o mesmo ID já registrado.
- `/meuid` — mostra o ID do usuário.
- `/idstatus` — administrador: mostra o status dos IDs.

## Railway
1. Suba estes arquivos no GitHub.
2. Crie o projeto no Railway usando o repositório.
3. Em Variables, crie `TOKEN` com o token do bot.
4. O Railway instala `requirements.txt` automaticamente.
5. O `Procfile` inicia o bot.

O bot precisa de **Gerenciar Apelidos** e o cargo dele deve estar acima dos cargos que ele precisa renomear.
